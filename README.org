* xiny-cli

A simple cli viewer for [[https://learnxinyminutes.com][Learn X in Y Minutes]].

** Usage

#+begin_source sh
xiny <lang> [<locale>]
#+end_source

By default, we pipe to less.
If less cannot be found, we dump to stdout.

** Compilation

#+begin_src sh
go build
#+end_src
